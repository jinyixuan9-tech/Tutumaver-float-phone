# Tutuma Float Phone 1.8.0

本次按完整版资源063及后续音乐卡定位修正，同步Chat内置美化与非YouTube灵动岛链路。

内置方案名称：kakao经典悬浮ui（0.30.1）、kakao经典平面ui（1.4.1）、kakao经典键位插件（0.13.1）。默认不强制套用会话CSS，插件保留原有设置。双方音乐卡的两颗点按卡片外沿镜像对齐。

Chat底层同步日期条、消息批次分组、气泡旁时间与未读标记、双语原文旁时间、头像基准、Emoji和语音转写布局。保留分享版现有MiniMax与iOS播放修复及桌面缩放。

Music同步卡片封面和时长回填、曲目绑定、播放/暂停/进度保存、群聊分享，以及完整音乐岛的控制、拖进度、音量和收起逻辑。消息/电话/Chat通话/反查/WVS的原有非YouTube接线已核对。

通用分享卡仅支持分享版已有应用；不加入YouTube代码、视频快照、分享壳和后台上岛。

验证：聊天排版/CSS作用域解析、消息日期与批次边界、音乐岛交互、旧音乐卡补齐、进度保存、插件迁移和分享版语音回归。类型与生产构建结果见提交说明。浏览器截图检查未执行。
