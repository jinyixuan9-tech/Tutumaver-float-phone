# 跨 App 记忆与联系人更新（2026-11-18）

## 共用改动

- SMS、Phone、LYSN、已结束的 WVS、iCity、X 及完整版 YouTube 的原生保存动作接入现有事件计数与自动总结阈值；重复保存、预览和只更新缓存不重复计数。关闭自动总结时不调用总结 API。
- SMS 正式接入角色的统一短期、长期、核心记忆，长期仍沿用原有「预算内全量、超过预算再向量/关键词筛选」策略。
- 保留当前号码完整原始短信的预算裁切，不再额外重复发送少量 Chat 摘录。不同陌生号码分别标识，疑似与确认仍分开；记录角色屏蔽、身份判断及发送失败，编辑/删除短信后清除旧关系摘要。
- Phone 保留当前逐字稿，按原消息 ID 排除重复 Chat；补入未接、拒接、取消、忙线等结果，不编造通话内容或未接原因。
- LYSN 读取角色本人的近期生活和选中的长期/核心记忆；不把私聊当粉丝留言，保留匿名、自主发言和沉默。开场白不再作为正式发布事件流回传。
- 群聊给个人经历保留知情成员标记；朋友圈 NPC 生成不再附带被评论角色的私人短期/长期/核心记忆。
- WVS 直播仍在结束后入记忆。User + 一位角色属于个人短期，多位角色实际同台才属于共享；补齐旧记录多人主播与旧参与摘要兼容。
- iCity 单篇删除与整本删除采用相同的直接来源撤销；共同日记按实际角色成员投影，历史日记逐日选择资料，使用日终视角，避免把后面的经历传给更早的日记。
- 补齐小游戏成员信息的保存/读取、多人剧情共享标记、在场访谈嘉宾的本人记忆。
- 增加短信、X、LYSN 来源开关；保留原有预设中的短期与记忆标记开关。没有对应预设标记时仍按既有规则不注入，不强行绕过用户预设。
- X 保留事件当时的匿名身份快照；X、小红书和电话的删除为后续机器总结保留直接来源撤销能力。旧的无来源总结不猜测删除。后来独立发生的 Chat、短信等对话仍需用户自行删除。
- 超长单条内容使用明确标记的首尾摘录，原始记录不变；短期仍按现有预算裁切。最终组装结果的 `_debugMeta.memoryContext` 记录短期事件来源及当前历史 ID，供本地排查；接口序列化不发送这项调试数据。
- 联系人角色卡加入「Chat 网名」，与 Chat 设置共用一份资料，主角色/配角/NPC 已建角色卡均可设置，不要求先加好友；不修改头像。
- 名片显示 Chat 网名、角色本身头像和 `Phone number`，号码沿用角色卡。未添加时点击进入原有添加朋友页，已添加时打开会话。
- Chat 加号增加「推荐好友名片」。只能推荐同世界的现有好友，排除当前对方及已有关系线者；发送成功后立即建立双向关系，可填写资料性质的关系备注，两位角色都能读取由 User 介绍认识的事件。群聊不提供此入口。

## 完整版独有

YouTube 仍要求直播结束并保存录播后才进入记忆。补齐主播独白、动作和未回复站内消息；摘要尚未生成时提供受限的原始记录摘录，而不使用过期摘要。共享归类与匿名身份分开；未读分享不再通过本地话题查找直接展开全文；历史生成不附加今天的世界线或后写的长期总结。

## 保持不变

核心记忆生成和读取的总体策略、长期的向量触发条件与预算配置保持原样。没有删除用户原始聊天，没有批量重建或覆盖现存记忆数据。分享版不加入 YouTube、浏览器或完整版其他独有功能。本次不更新 IPA。

## 验证与边界

运行 `node scripts/check-cross-app-memory.cjs`、TypeScript 检查和 `npm run android:web`。回归直接调用生产组装函数，并检查 OpenAI 兼容接口序列化后的请求；不使用用户数据，不调用真实 LLM 或 Embedding API。模型是否在实际自由对话中遵守匿名和表达边界，仍需真实角色使用回归；当前环境没有完成手机触屏界面的实机验收。

已存在的 `check-social-identities.cjs` 依赖过期的测试桩，分享版还引用了本版不存在的 YouTube 文件，不作为本次通过项。对应号码隔离、匿名、共享归类由新的跨 App 回归覆盖。
