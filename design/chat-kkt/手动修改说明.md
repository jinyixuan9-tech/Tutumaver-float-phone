# Chat CSS 手动修改说明

适用于玻璃v0.30.2、平面v1.4.2，配套共通JS v0.13.1，资源062。此轮为整理版，不改变已确认的外观；包含玻璃输入文字下移3px的修正。

## 使用与定位

选择一种风格，完整替换旧CSS；不要把两版叠加。JS继续使用0.13.1，不需要重装。普通输入占位文字由JS提供，CSS负责颜色和位置。

CSS依次分为：共通常用参数、内部图片资源、独立翻译模块、共通消息样式、风格专用顶栏／底栏／引用。顶部参数后就结束常用设置区；后面的长base64是图片，不是可删除的重复代码。两版消息样式和翻译模块由同一份源码生成。

每行参数旁已有中文注释。先备份，每次只改一两项，在同一聊天室的日间与夜间都看一下。长度带px；行高倍数不带单位；颜色可用十六进制。应用文字缩放会继续影响字号。不要全局替换相同数字，它们可能属于不同控件。

## 常见修改

- 原文缩小：改`--ii-text-size`；气泡边框内留白改`--ii-bubble-pad-x`和`--ii-bubble-pad-y`。翻译大小另改`--ii-translation-font-size`。
- 消息更紧凑：先小幅改`--ii-message-gap`。字幕高度、卡片和连续消息结构仍会影响实际间距，不能只靠它控制所有空白。
- 字幕上移：`--ii-translation-top-gap`由-3px改为-4px。不要改成绝对定位，也不要用大幅负间距，会遮住原文或下一条消息。
- 头像尺寸：双方分别改`--ii-self-avatar-size`和`--ii-other-avatar-size`。目前都是36px；若只改尺寸，保留圆角和遮罩参数。原生遮罩仍参与最终轮廓，仅改圆角数值不保证形状随之改变。
- 显示我方头像与名字：删除顶部标明“默认隐藏我方头像和网名BEGIN／END”的整块。仅改头像大小不会取消隐藏。
- 地图单独变窄：把`--ii-map-card-width`的var(...)改成例如220px；不会改变转账卡。
- 更换译文风格：完整替换“翻译模块BEGIN／END”内的部分。单独的translation-subtitles.css是相同模块的副本，无需重复导入。

## 输入栏与风格专用参数

`--ii-input-min-height`是旧共通基础值，当前被专用输入栏规则覆盖：玻璃最小32px，平面最小36px。调整高度时应在文件末尾风格专用区查找对应`.chat-input-textarea`规则中的min-height，不要以为只改顶部参数就会生效。

玻璃输入文字当前位置：padding为8px 3px 2px，上下总内边距10px；保持总和不变，将上内边距增加1px、下内边距减少1px，文字就下移1px。平面输入文字保持原位置。这项会同时影响占位文字和实际输入文字，不需要改JS。

平面发送前引用条位于输入栏上方。专用区`--ii-flat-quote-height`为28px；日间`--ii-flat-quote-bg`为#fff，夜间为#29292d；`--ii-flat-quote-ink`为文字色，`--ii-flat-quote-rule`为底部分隔线色。调高度时保留底部留白联动规则，避免遮住末条消息。

平面输入栏颜色集中在专用区末部：`--ii-flat-bar-surface`为整条底栏背景，`--ii-flat-input-surface`为输入框背景，`--ii-flat-input-ink`为输入文字，`--ii-flat-placeholder`为占位文字。夜间定义带!important；改夜间色就修改该夜间规则，不要只改日间值。

加号菜单宽度参数不控制表情包面板。表情面板目前统一为手机宽度减38px并居中；如需改左右留白，请定位表情面板规则，避免连同底栏一起改宽。

## 本次整理范围与限制

按语法结构检查了四个CSS模块，没有发现整条完全一致、同优先级的重复规则。确认平面夜间输入栏有4条普通优先级颜色变量，已被后面的同名!important值覆盖；删除了这组旧声明，其余覆盖保留。日夜规则、WebKit前缀、遮罩、二级样式层及兼容原生结构的选择器都有用途，不能见到相似就删。

已拆清常用参数与内部图片资源，逐条排版样式声明，保留选择器、数值、规则先后与优先级。源码验证以语法和声明对照为准；本次环境无法启动浏览器，仍以手机实际显示为最终确认。文件变长主要因为排版和中文说明，并非增加新的视觉效果。

音乐卡两点定位修正：发出侧保持右上角；收到侧改为左上角镜像，边缘留白相同。

PLAYLIST标签顺序：对方是“PLAYLIST 歌手”，我方是“歌手 PLAYLIST”；两种美化均遵循这个镜像顺序。
