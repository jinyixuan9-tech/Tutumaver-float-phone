# Chat 共通样式源码

玻璃版与平面版共用 `common.css` 和 `translation-subtitles.css`，仅各自的 `*-chrome.css` 区分顶栏、底栏及引用／回复。运行 `node scripts/build-chat-kkt-styles.cjs` 生成两份完整 CSS；不要分别修改生成文件的共通部分。

生成文件完整替换当前会话 CSS，只选择一种风格。配套 JS v0.13.1；没有新增回车拦截或强制展开译文。现已作为资源063的可选内置方案提供。

当前输出为玻璃v0.29.2 / 平面v1.3.3。本轮仅CSS调整：恢复地图绿色原生图标，音乐装饰点统一按文字区右边缘向内8px定位，PLAYLIST在歌手名前；正文13px、气泡内边距6px/10px、字幕13px并上移4px，表情面板统一按手机宽度减38px居中。

先安装资源062：其中的 CSS 作用域转换支持无大括号的 `@layer` 排序语句。使用二级样式层使翻译、布局修正的优先级独立于图标插件先后加载。

完整 CSS 顶部可调整双方头像、消息间距、语音、卡片等参数。当前CSS默认双方聊天头像36px，保持原遮罩与圆角不变；联系人、个人区、朋友圈等非聊天页面保留各自原有尺寸。要显示我方头像和网名，删除标明的隐藏区块。更换翻译时整体替换“翻译模块 BEGIN / END”；独立翻译文件是该模块的副本，不需额外叠加。

验证：TypeScript、生产构建、既有聊天和音乐检查、分层排序解析回归。另用真实DOM和源码CSS做59项样式级联检查，覆盖两版日夜模式、图标插件先建立样式层的顺序，以及共通区逐字一致。浏览器渲染在本次环境中不可用，实际手机显示仍需复测。

字幕层级修正：译文保留正常文档流和上移4px的参数，使用相对定位/z-index:2，原文行z-index:0；每条双语块隔离层叠，避免字幕上沿被原文气泡遮住。本轮不改其他尺寸与布局。
